# 装甲板检测算法详解

## 功能简介与Pipeline

装甲板检测是自瞄系统的前端核心算法，负责从相机图像中定位敌方机器人装甲板的位置和类别。系统支持三种识别方案：

**【传统识别】**
对相机传入的图像进行二值化处理，提取灯条轮廓，筛选符合条件的灯条对，匹配形成装甲板候选，通过几何约束验证后得到装甲板在图像坐标系下的位置。

**【神经网络】**
利用深度学习模型（YOLO系列）直接从图像中回归装甲板的边界框、类别和4个角点坐标，端到端完成检测任务。

**【融合算法】**
结合神经网络与传统识别的优势，利用YOLO进行粗筛定位，再通过传统方法的几何约束和PCA角点优化进行精细化校正，在保证检测速度的同时提升精度。

**【完整Pipeline】**
```
相机输入图像 (1280×720)
      ↓
┌─────────────────────────────────┐
│   YOLO粗筛（神经网络）           │
│   - 边界框回归                   │
│   - 类别分类（38类）             │
│   - 4角点预测                   │
└─────────────────────────────────┘
      ↓ 粗略检测结果
┌─────────────────────────────────┐
│   传统方法精提取                 │
│   - 灯条轮廓提取                 │
│   - 几何约束验证                 │
│   - PCA主轴方向计算             │
└─────────────────────────────────┘
      ↓ 优化后的角点
┌─────────────────────────────────┐
│   亚像素精化                     │
│   - Sobel算子梯度搜索           │
│   - findCornerSubPix            │
└─────────────────────────────────┘
      ↓ 最终检测结果
┌─────────────────────────────────┐
│   NMS去重 & 分类器验证           │
│   - IoU阈值过滤                  │
│   - 数字识别（ResNet）           │
└─────────────────────────────────┘
      ↓
装甲板信息 (边界框、4角点、类别)
      ↓
后续模块：PnP位姿解算 → EKF状态估计 → MPC轨迹规划
```

## YOLO算法原理

### 一、YOLO基本思想

传统的目标检测算法（如R-CNN系列）采用两阶段方法：首先生成候选区域（Region Proposal），然后对每个区域进行分类和回归。这种方法精度高但速度慢。

YOLO（You Only Look Once）将目标检测重构为单阶段回归问题，直接在图像的密集网格上预测边界框和类别概率，实现端到端的实时检测。

**核心思想**：
将图像划分为 $S \times S$ 的网格，每个网格单元负责检测中心落在该网格内的目标。每个网格预测 $B$ 个边界框及其置信度，以及 $C$ 个类别的概率。

### 二、网络结构

#### 2.1 整体架构

YOLO采用**特征金字塔网络（FPN）**架构，包含三个主要部分：

**主干网络（Backbone）**：CSPDarknet53，输出三个不同尺度的特征图
- C3: $80 \times 80$（检测小目标）
- C4: $40 \times 40$（检测中目标）
- C5: $20 \times 20$（检测大目标）

**特征融合（Neck）**：PANet，融合不同尺度特征，增强语义信息

**检测头（Head）**：每个位置预测 $B$ 个边界框

#### 2.2 PANet特征金字塔

**自顶向下路径**（上采样+拼接）：
$$P_5 = C_5, \quad P_4 = \text{UpSample}(P_5) \oplus C_4, \quad P_3 = \text{UpSample}(P_4) \oplus C_3$$

**自底向上路径**（下采样+拼接）：
$$N_3 = P_3, \quad N_4 = \text{DownSample}(N_3) \oplus P_4, \quad N_5 = \text{DownSample}(N_4) \oplus P_5$$

装甲板检测应用：$N_3$ 检测远距离小装甲板，$N_4$ 检测中距离，$N_5$ 检测近距离大装甲板。

#### 2.3 装甲板特殊适配：角点预测

传统YOLO只预测边界框 $(x, y, w, h)$，但PnP解算需要精确的4个角点坐标。

让YOLO额外预测4个角点：
$$\mathbf{k} = [k_1^x, k_1^y, k_2^x, k_2^y, k_3^x, k_3^y, k_4^x, k_4^y]^T$$

每个检测结果包含13个值：4个边界框参数 + 1个置信度 + 8个角点坐标。

**类别定义**：38类（红/蓝/灰各9号装甲板 + 背景干扰）

### 三、损失函数

$$\mathcal{L} = \mathcal{L}_{\text{box}} + \mathcal{L}_{\text{conf}} + \mathcal{L}_{\text{cls}}$$

**边界框回归**：CIoU Loss，同时优化重叠度、中心距离和长宽比一致性

**置信度**：二元交叉熵，正负样本不平衡时使用 Focal Loss

**分类**：交叉熵损失

## OpenVINO推理框架

### 一、模型转换

PyTorch 训练的 YOLO 模型需转换为 OpenVINO IR 格式：

1. 导出为 ONNX 格式
2. 使用 Model Optimizer 转换为 `.xml`（网络结构）+ `.bin`（权重）

转换过程中自动进行算子融合、常量折叠、精度转换（FP32 → FP16）。

### 二、预处理管道

输入图像 $\mathbf{I}_{\text{raw}} \in \mathbb{R}^{H \times W \times 3}$（BGR, uint8）经过：

1. **保持纵横比缩放**：$s = \min(640/W, 640/H)$
2. **Letterbox填充**：居中放置，四周补黑边至 $640 \times 640$
3. **OpenVINO自动处理**：uint8 → float32，BGR → RGB，除以255，NHWC → NCHW

### 三、性能

| 配置 | 推理速度 |
|---|---|
| CPU + LATENCY | ~4.2ms |
| GPU + LATENCY | ~2.4ms |

完整 pipeline（YOLO + 传统验证 + 分类器）约 5.1ms，满足 100+ FPS 要求。

**硬件选择**（YAML 配置）：
```yaml
device: "CPU"   # 通用
device: "GPU"   # 需要 OpenCL，速度提升约 75%
device: "AUTO"  # 自动选择
```

## 双重验证机制

### 一、传统方法精提取

YOLO 角点精度约 0.5-1 像素，PnP 解算要求 <0.3px，需传统方法精化。

**步骤**：
1. 灰度化 → 自适应二值化 → 轮廓检测
2. PCA 主成分分析计算灯条主轴方向
3. 沿主轴方向搜索 Sobel 梯度极值点，精化到亚像素

**几何约束验证**：
- 尺寸约束：$w, h \in [10\text{cm}, 50\text{cm}]$
- 长宽比：$1.0 \leq w/h \leq 5.0$
- 灯条平行度：$|\theta_1 - \theta_2| < 10°$

### 二、分类器验证

使用 ResNet 对装甲板数字进行二次分类，输出9类概率，置信度 > 0.5 才接受。

### 三、NMS去重

按置信度降序排列，IoU > 0.3 的重叠检测被抑制，保留最高置信度结果。

## 性能对比

| 场景 | 纯YOLO | 纯传统 | 融合方法 |
|---|---|---|---|
| 正常光照检测率 | 98.2% | 94.7% | **99.1%** |
| 复杂光照检测率 | 95.5% | 88.2% | **98.5%** |
| 正常光照误检率 | 3.8% | 8.1% | **1.2%** |
| 角点平均误差 | 0.45px | — | **0.24px** |

融合方法在检测率、误检率、角点精度三个维度均优于单一方法。
