## 系统概述

### EKF在系统中的作用
在RoboMaster自瞄系统中，EKF负责**目标状态估计**，包括：
- 目标位置（x, y, z）
- 目标速度（vx, vy, vz）
- 旋转角度（angle）和角速度（angular_velocity）
- 机器人几何参数（半径r、长短轴差l、高度差h）

### 数据流
```
检测器（装甲板位置）
    ↓
EKF更新（融合观测）
    ↓
轨迹预测（补偿系统延迟）
    ↓
规划器（生成控制指令）
```

## 状态向量和协方差矩阵

### 状态向量 x (11维)
```cpp
x = [x, vx, y, vy, z, vz, angle, ω, r, l, h]
```

| 索引 | 变量 | 物理意义 | 单位 |
|------|------|----------|------|
| 0,2,4 | x,y,z | 旋转中心坐标 | m |
| 1,3,5 | vx,vy,vz | 速度分量 | m/s |
| 6 | angle | 旋转角度 | rad |
| 7 | ω | 角速度 | rad/s |
| 8 | r | 旋转半径 | m |
| 9 | l | 长短轴差(r2-r1) | m |
| 10 | h | 高度差(z2-z1) | m |

### 协方差矩阵 P
**初始值 P0** 表示对初始状态的不确定度。值越大，滤波器对初始状态的信任度越低，收敛越慢但更稳定。

**参考值**（tasks/auto_aim/tracker.cpp:245-261）：

```cpp
// 平衡机器人 (2个装甲板)
P0_dig = {1, 64, 1, 64, 1, 64, 0.4, 100, 1, 1, 1}

// 哨兵 (3个装甲板)
P0_dig = {1, 64, 1, 64, 1, 81, 0.4, 100, 1e-4, 0, 0}

// 前哨站 (3个装甲板)
P0_dig = {1, 64, 1, 64, 1, 64, 0.4, 100, 1e-4, 0, 0}

// 标准/英雄 (4个装甲板)
P0_dig = {1, 64, 1, 64, 1, 64, 0.4, 100, 1e-5, 1, 1}
```

## 核心参数详解

### 1. 初始协方差 P0

#### 位置协方差 (x, y, z) - 索引 [0, 2, 4]
```cpp
P0[0] = P0[2] = P0[4] = 1.0  // 位置初始方差 (m²)
```

**调参建议：**
- **增大** (如 2.0~5.0)：初始检测距离误差大时，滤波器更保守
- **减小** (如 0.1~0.5)：初始检测准确时，加快收敛

**场景示例：**
- 远距离检测（>5m）：建议 2.0~3.0
- 近距离检测（<3m）：建议 0.5~1.0

#### 速度协方差 (vx, vy, vz) - 索引 [1, 3, 5]
```cpp
P0[1] = P0[3] = 64.0  // 速度初始方差 (m²/s²)
P0[5] = 81.0          // 哨兵Z轴速度方差更大
```

**调参建议：**
- **增大** (如 100~200)：目标速度变化剧烈时（小陀螺）
- **减小** (如 25~49)：目标运动平稳时

**物理含义：** 标准差 √P = 8 m/s，表示初始速度估计可在 ±8 m/s 范围内

#### 角度协方差 - 索引 [6]
```cpp
P0[6] = 0.4  // 角度初始方差 (rad²)
```

**调参建议：**
- **增大** (如 1.0)：初始角度估计不准时
- **减小** (如 0.1)：检测器角度准确时

**注意：** 角度使用模运算，方差过大会导致收敛问题

#### 角速度协方差 - 索引 [7]
```cpp
P0[7] = 100.0  // 角速度初始方差 (rad²/s²)
```

**调参建议：**
- **小陀螺场景**：建议 150~200（角速度可达 2~3 rad/s）
- **静止/慢速**：建议 25~50

#### 几何参数协方差 - 索引 [8, 9, 10]
```cpp
// 4装甲板机器人
P0[8] = 1e-5  // 半径r (已知)
P0[9] = 1     // 长短轴差l (未知)
P0[10] = 1    // 高度差h (未知)

// 3装甲板机器人
P0[8] = 1e-4  // 半径r (已知)
P0[9] = 0     // 固定半径
P0[10] = 0    // 固定高度
```

**原则：** 已知参数给极小值，未知参数给较大值

### 2. 过程噪声 Q

**位置：** `tasks/auto_aim/target.cpp:98-117`

```cpp
// 分段白噪声模型
v1 = 0.9;   // 线加速度方差 (m²/s⁴)
v2 = 100;   // 角加速度方差 (rad²/s⁴)

// Q矩阵结构
Q = {
    {a*v1, b*v1, 0,    0,    ...},  // x, vx
    {b*v1, c*v1, 0,    0,    ...},
    {0,    0,    a*v1, b*v1, ...},  // y, vy
    ...
    {0,    0,    0,    0,    a*v2, b*v2, ...},  // angle, ω
}
```

其中：
```
a = dt⁴/4,  b = dt³/2,  c = dt²
```

#### 线加速度方差 v1
**当前值：** 0.9

**调参建议：**
- **目标机动性强**：增大到 1.5~3.0
- **目标运动平稳**：减小到 0.3~0.6
- **调参原则**：v1 ∝ (最大加速度)²

**场景示例：**
- 英雄机器人（加速能力强）：v1 = 1.5~2.0
- 步兵机器人（加速一般）：v1 = 0.9~1.2
- 哨兵（运动受限）：v1 = 0.5~0.8

#### 角加速度方差 v2
**当前值：** 100

**调参建议：**
- **小陀螺模式**：增大到 150~200
- **正常旋转**：保持 100
- **慢速旋转**：减小到 50~80

**特殊处理**（target.cpp:128-129）：
```cpp
// 前哨站高速旋转时，限制角速度为 ±2.51 rad/s
if (name == outpost && abs(ω) > 2) {
    ω = ω > 0 ? 2.51 : -2.51;
}
```

### 3. 测量噪声 R

**位置：** `tasks/auto_aim/target.cpp:187-195`

```cpp
auto center_yaw = atan2(armor.y, armor.x);
auto delta_angle = limit_rad(armor.yaw - center_yaw);

R_dig = {
    4e-4,                                    // yaw方差 (rad²)
    4e-4,                                    // pitch方差 (rad²)
    log(|delta_angle| + 1) + 1,              // 距离方差 (m²)
    log(|armor.distance| + 1) / 200 + 9e-2   // 角度方差 (rad²)
};
```

#### 自适应机制

**距离方差（索引2）：**
```cpp
R_distance = log(|delta_angle| + 1) + 1
```
- 当装甲板侧面朝向相机时，delta_angle大 → 距离测量不准 → R增大
- 正面朝向时，delta_angle小 → R接近最小值1

**角度方差（索引3）：**
```cpp
R_angle = log(distance + 1) / 200 + 0.09
```
- 距离越远，角度估计越不准 → R增大

#### 调参建议

**基础噪声水平：**
```cpp
// yaw/pitch
R[0] = R[1] = 4e-4  // 约0.02 rad ≈ 1°

// 距离
R_base = 1.0         // 最小值1m
R_max ≈ 2.4         // 最大值（delta_angle=2.4rad时）

// 角度
R_angle_min = 0.09   // 约5°
R_angle_max ≈ 0.15   // 距离10m时
```

**调整策略：**
- **检测器精度高**：减小R_base到0.5~0.8
- **检测器精度低**：增大R_base到1.5~2.0
- **近距离场景**：可以适当减小所有R值

## 调参流程

### 阶段1：数据采集
```bash
# 运行带录屏的测试程序
./build/auto_aim_test

# 或使用离线数据测试
./build/planner_test_offline <recorded_data>
```

**需要关注的指标：**
1. **NIS (Normalized Innovation Squared)**
   - 理想范围：[0, 0.711]（95%置信区间）
   - 位置：`ekf_.data["nis"]`

2. **残差 (residual)**
   - `ekf_.data["residual_yaw"]`
   - `ekf_.data["residual_pitch"]`
   - `ekf_.data["residual_distance"]`
   - `ekf_.data["residual_angle"]`

3. **收敛失败率**
   - `ekf_.data["recent_nis_failures"]`
   - 阈值：>40% 说明参数不匹配

### 阶段2：初步调参

#### Step 1: 调整P0
```
目标：让NIS在理想区间内的比例 > 80%

方法：
1. 固定Q和R
2. 根据初始状态不确定性调整P0
3. 观察前10帧的NIS变化
```

#### Step 2: 调整Q
```
目标：预测误差合理，不过度信任模型

方法：
1. 观察速度估计的平滑度
2. 如果速度抖动严重 → 增大Q（给模型更多信任）
3. 如果速度响应太慢 → 减小Q（给观测更多信任）
```

#### Step 3: 调整R
```
目标：测量噪声水平准确反映实际

方法：
1. 统计静止目标的测量方差
2. 将R设置为略小于统计方差（EKF会自动补偿）
3. 检查自适应公式是否合理
```

### 阶段3：验证优化

#### 收敛性测试
```cpp
// 检查位置（target.cpp:237-246）
bool Target::diverged() const {
    auto r_ok = ekf_.x[8] > 0.05 && ekf_.x[8] < 0.5;
    auto l_ok = ekf_.x[8] + ekf_.x[9] > 0.05 && ekf_.x[8] + ekf_.x[9] < 0.5;
    return !(r_ok && l_ok);
}
```

**调参目标：**
- 发散率 < 5%
- 收敛帧数：标准3帧，前哨站10帧

#### 跟踪性能测试
```
测试场景：
1. 静止目标（5秒）
2. 匀速运动（5秒）
3. 小陀螺（5秒）
4. 加速运动（5秒）

评估指标：
- 位置RMSE < 0.1m
- 速度RMSE < 0.5m/s
- 角度RMSE < 0.1rad
```

## 常见问题与解决方案

### 问题1：滤波器发散
**症状：**
- 半径估计超出 [0.05, 0.5] m
- NIS持续 > 0.711

**原因分析：**
1. 初始P0过大 → 不确定度累积
2. Q过大 → 模型预测不可信
3. R过小 → 过度信任错误观测

**解决方案：**
```cpp
// 方案1：减小P0（尤其是速度和角速度）
P0[1] = P0[3] = 36;  // 从64减到36
P0[7] = 50;          // 从100减到50

// 方案2：减小Q
v1 = 0.5;  // 从0.9减到0.5
v2 = 60;   // 从100减到60

// 方案3：增大R
R_base = 1.5;  // 从1.0增到1.5
```

### 问题2：响应速度慢
**症状：**
- 目标加速时，估计速度滞后明显
- 轨迹预测偏差大

**原因分析：**
1. Q过小 → 滤波器过度依赖历史
2. P0过小 → 初始估计过于自信
3. R过大 → 观测权重过低

**解决方案：**
```cpp
// 方案1：增大Q（加速响应）
v1 = 1.5;  // 从0.9增到1.5

// 方案2：增大速度P0
P0[1] = P0[3] = 100;  // 从64增到100

// 方案3：减小R
R_base = 0.7;  // 从1.0减到0.7
```

### 问题3：小陀螺跟踪不稳定
**症状：**
- 角速度估计震荡
- 装甲板匹配跳变

**解决方案：**
```cpp
// 1. 增大角速度过程噪声
v2 = 150;  // 从100增到150

// 2. 增大角速度初始协方差
P0[7] = 150;  // 从100增到150

// 3. 检查装甲板匹配逻辑（target.cpp:134-180）
// 可能需要调整角度误差阈值
```

### 问题4：NIS失败率过高
**症状：**
- `recent_nis_failures` > 40%

**排查步骤：**
1. **检查Q/R比例**
   ```
   理论上：trace(Q) / trace(R) ≈ 实际噪声比
   ```

2. **检查测量偏差**
   ```cpp
   // 打印残差统计
   logger()->info("residual_yaw: {:.3f}", ekf_.data["residual_yaw"]);
   logger()->info("residual_pitch: {:.3f}", ekf_.data["residual_pitch"]);
   ```

3. **调整NIS阈值**（extended_kalman_filter.cpp:66-67）
   ```cpp
   // 当前使用4自由度95%置信度
   constexpr double nis_threshold = 0.711;
   // 如果调整自由度，需查卡方分布表
   ```

## 实战案例

### 案例1：优化英雄机器人跟踪

**问题描述：**
- 英雄机器人加速能力强，现有参数v1=0.9导致预测滞后
- 远距离（>6m）跟踪时，位置抖动明显

**调参过程：**

```cpp
// 初始参数
P0 = {1, 64, 1, 64, 1, 64, 0.4, 100, 1e-5, 1, 1};
v1 = 0.9; v2 = 100;
R_base = 1.0;

// 第一次迭代：增大过程噪声
P0 = {1, 100, 1, 100, 1, 64, 0.4, 150, 1e-5, 1, 1};  // 增大速度协方差
v1 = 1.5; v2 = 150;  // 增大加速度方差

// 结果：响应变快，但远距离抖动仍存在

// 第二次迭代：自适应R
// 在远距离时增大R（修改target.cpp:191）
auto dist_factor = std::min(armor.ypd_in_world[2] / 8.0, 1.5);
R_dig[2] = (log(std::abs(delta_angle) + 1) + 1) * dist_factor;

// 最终效果：
// - 近距离RMSE: 0.08m ↓ 0.05m
// - 远距离RMSE: 0.15m ↓ 0.09m
```

### 案例2：前哨站小陀螺优化

**问题描述：**
- 前哨站高速旋转（2.5 rad/s）时，角度估计震荡
- 装甲板切换时跟踪丢失

**调参过程：**

```cpp
// 初始参数（和标准机器人相同）
P0 = {1, 64, 1, 64, 1, 64, 0.4, 100, 1e-4, 0, 0};
v2 = 100;

// 第一次迭代：角速度专用调参
P0[7] = 200;  // 大幅增大角速度协方差
v2 = 200;     // 增大角加速度方差

// 结果：角度估计稳定，但装甲板匹配仍有问题

// 第二次迭代：放宽匹配阈值（target.cpp:154-165）
// 将角度误差权重降低
auto angle_error = std::abs(limit_rad(armor.yaw - xyza[3])) * 0.5 +
                   std::abs(limit_rad(armor.pitch - ypd[0]));

// 结果：匹配稳定，NIS失败率 < 10%

// 最终参数：
P0_outpost = {1, 64, 1, 64, 1, 64, 0.4, 200, 1e-4, 0, 0};
v2 = 200;
```

## 调参检查清单

### 参数合理性检查
- [ ] P0对角线元素 > 0
- [ ] Q矩阵半正定（v1 > 0, v2 > 0）
- [ ] R矩阵对角线元素 > 0
- [ ] P0速度项 > P0位置项（通常64倍关系）
- [ ] Q/R比例在合理范围（1~100）

### 运行时检查
- [ ] NIS < 0.711的比例 > 80%
- [ ] 残差无直流偏置（均值≈0）
- [ ] 收敛帧数符合预期（标准3帧）
- [ ] 发散率 < 5%
- [ ] 速度估计无明显抖动

### 特殊场景检查
- [ ] 目标静止：收敛到正确位置
- [ ] 目标匀速：速度估计准确
- [ ] 目标加速：预测无严重滞后
- [ ] 小陀螺：角度跟踪稳定
- [ ] 装甲板切换：无跳变

## 参考公式

### 卡方检验阈值
```cpp
// 自由度=4，置信度95%
nis_threshold = 0.711;
nees_threshold = 0.711;

// 如果测量维度改变，需重新计算
// 使用 scipy.stats.chi2.ppf(0.95, df)
```

### 状态转移方程
```cpp
// 线性部分（位置/速度）
x[k+1] = x[k] + vx[k] * dt
vx[k+1] = vx[k] + ax[k] * dt

// 角度部分（特殊处理）
angle[k+1] = limit_rad(angle[k] + ω[k] * dt)
```

### 约瑟夫形式协方差更新
```cpp
// 稳定性优于传统公式（extended_kalman_filter.cpp:54）
P = (I - K*H) * P * (I - K*H)^T + K * R * K^T;
```

## 总结

### 核心原则
1. **P0反映初始不确定性**：已知参数给小值，未知参数给大值
2. **Q反映模型准确性**：目标机动性越强，Q越大
3. **R反映测量精度**：检测器越好，R越小
4. **三者相互影响**：调整一个时需考虑其他两个

### 调参策略
- **保守起步**：从参考值开始，逐步调整
- **单一变量**：每次只调整一个参数
- **数据驱动**：用NIS和残差作为客观指标
- **场景验证**：在多种运动模式下测试

### 快速参考
| 参数 | 作用 | 增大效果 | 减小效果 |
|------|------|----------|----------|
| P0 | 初始不确定度 | 收敛慢但稳定 | 收敛快但敏感 |
| Q | 过程噪声 | 响应快但抖动 | 平滑但滞后 |
| R | 测量噪声 | 信任模型 | 信任观测 |
