# R 自适应 + 新息门控：改动与验证记录

> 目的：针对 `heavy_aim_baseline.md` 误差预算里"距离→抬枪 1.30 mrad"这一项，
> 以及"粗差污染状态"的稳定性问题。两项改动都在 `tasks/auto_aim/target.cpp`。
>
> **验证方式**：C++ 无法在本机编译，故用 Python+NumPy 复刻 `target.cpp` 的
> 观测模型（状态 `x y a z vx vy w`、观测 `los pitch dist armor_yaw`、
> 解析 Jacobian 同构）做 Monte Carlo。**这不是实车验证**，实车仍需按
> `heavy_aim_baseline.md` 的 O/B 层复验。

## 1. R 自适应（观测噪声随视角放大）

### 1.1 动机

`R_dig` 原来的语义（见 `docs/ekf_model.md`）：

| 下标 | 物理量 | 原表达 |
|---|---|---|
| 0 | yaw 方差 (rad²) | `r_yaw`（常数）|
| 1 | pitch 方差 (rad²) | `r_pitch`（常数）|
| 2 | **距离方差 (m²)** | `log(|delta_angle|+1)+1` |
| 3 | 角度方差 (rad²) | `log(dist+1)/200 + r_dist_base` |

问题：板面与视线夹角越大（侧视），板在图像上被压扁，由**单板 PnP** 反解出的
距离与 yaw 都迅速病态（`sigma_d ∝ 1/cos`）。而 `r_yaw` 是常数、
距离方差只随 `|delta_angle|` **对数**微增 —— 等于假设"侧视和正视一样可信"。

### 1.2 改法

```cpp
const double cos_view = std::abs(std::cos(delta_angle));
const double view_penalty = 1.0 / std::max(cos_view, 0.5);   // 最多降权 2 倍

R_dig = { r_yaw * view_penalty,                  // yaw：侧视压缩，噪声大
          r_pitch,                               // pitch：与视角弱相关
          (log(|delta_angle|+1) + 1) * view_penalty,  // 距离：侧视最病态，重点降权
          log(dist+1)/200 + r_dist_base };
```

**floor 为什么取 0.5 而不是 0.25**：做过拟合对照（见 §1.3），floor=0.25 在
"噪声其实不随侧视恶化"的工况下会让位置 RMSE 从 67.0 → 70.7 mm（+5.5%），
floor=0.5 只劣化 1.8% 却保留大部分收益。

### 1.3 验证（8 m、2 rad/s 自转，视角从正视转到侧视）

**A) 真实噪声随侧视放大（物理真实）**

| 方案 | 位置 RMSE | 朝向 RMSE | NIS 越限% |
|---|---|---|---|
| 固定 R（原版） | 128.2 mm | 0.591° | 3.5 |
| 自适应 floor=0.25 | 110.7 mm | 0.529° | 0.5 |
| **自适应 floor=0.5（采用）** | **115.5 mm** | **0.543°** | 1.0 |
| 自适应 floor=0.75 | 120.4 mm | 0.565° | 2.0 |

**B) 真实噪声各向同性（过拟合检验）**

| 方案 | 位置 RMSE | 朝向 RMSE |
|---|---|---|
| 固定 R | 67.0 mm | 0.429° |
| 自适应 floor=0.25 | **70.7 mm（+5.5%，变差）** | 0.403° |
| 自适应 floor=0.5 | 68.2 mm（+1.8%） | 0.406° |

**结论**：floor=0.5 是收益/鲁棒的最优折中：物理真实场景改善 **10%**，
假设不成立时只劣化 1.8%。

## 2. 新息门控（Innovation Gating）

### 2.1 动机

`r/l/h` 三个参数在 `Q` 里**没有过程噪声**，一旦被脏观测（误检、另一台车的板、
反射）污染就**不可逆** —— 这正是历史上"幽灵板 d=0.30 m"的成因。

原实现里 `tracker.cpp` 只有**球形空间门控**（`gate = 1.0 + 0.2*dist`），
它比较的是"观测位置 vs 预测位置"的欧氏距离，**不利用滤波器自身的不确定度**。

### 2.2 改法

在 `Target::update_ypda()` 里、`ekf_.update()` **之前**做卡方检验：

```cpp
constexpr double kInnovationGateChi2 = 18.47;   // chi2(4, 0.999)
Eigen::VectorXd nu = z_subtract(z_now, h(ekf_.x));      // 新息（角度已 wrap）
Eigen::MatrixXd S  = H * ekf_.P * H.transpose() + R;    // 新息协方差
const double d2 = (nu.transpose() * S.inverse() * nu)(0, 0);
if (std::isfinite(d2) && d2 > kInnovationGateChi2) return;   // 丢弃本帧观测
```

**为什么取 99.9%（18.47）而不是 95%（9.488）**：这里只拦**粗差**。
正常机动、换板造成的中等残差应由 R 自适应平滑吸收；门槛过严会误杀真实的大机动观测、
拖慢重捕。实测也支持（见下：95% 会误杀 0.4% 的正常观测）。

### 2.3 验证

**A) 8% 观测为粗差（模拟误检/相邻车）**

| 配置 | 位置 RMSE | 朝向 RMSE | 被拒比例 |
|---|---|---|---|
| 原版（固定 R，无门控） | 1810.7 mm | 7.047° | 0% |
| 仅 R 自适应 | 1761.0 mm | 4.739° | 0% |
| 仅新息门控 | 106.0 mm | 0.838° | 7.7% |
| **R 自适应 + 新息门控（本次）** | **104.9 mm** | **0.887°** | 7.6% |

**B) 无粗差（检验是否误杀）**

| 配置 | 位置 RMSE | 朝向 RMSE | 被拒比例 |
|---|---|---|---|
| 原版 | 94.6 mm | 0.500° | 0% |
| **R 自适应 + 新息门控** | **90.6 mm** | **0.465°** | **0%** |

**门控阈值对照（无粗差时）**：18.47 → 误杀 **0.0%**；9.488 → 误杀 0.4%。
故取 18.47。

## 4. 注意事项（上线前必查）

1. **NIS 分布会变**：R 变大 → NIS 变小 → `Tracker` 的 Bad Converge 看门狗
   （比例 ≥40%、样本 ≥30）**变得更迟钝**。R 自适应在物理真实场景下把 NIS 越限率
   从 3.5% 压到 1.0%，需重新确认看门狗仍能在真发散时触发。
2. **门控与看门狗同族统计量**：门控丢弃观测 → 样本积累变慢，两者需一起调。
3. **未做实车验证**：本文全部为模型级 Monte Carlo。实车需按
   `heavy_aim_baseline.md` §3 的 O 层（`rdbg metrics` 看 NIS / armor_id / w 过零）
   与 B 层（静态靶）复验。
4. **`delta_angle` 的符号**：`cos_view = |cos(delta_angle)|` 取了绝对值，
   因此正/侧视对称 —— 符合物理（两侧侧视一样病态）。

## 5. 回滚方式

改动集中在 `target.cpp` 单文件，回滚只需：
- R：把三处 `* view_penalty` 去掉，恢复常数 `r_yaw` 与 `log(...)+1`；
- 门控：删掉 `kInnovationGateChi2` 那个作用域块。

`tracker.cpp` **未做改动**（曾尝试"旋转方向门控"，因把"视线方位角"与"装甲板朝向"
混为一谈而撤销，详见开发记录）。
