## 为什么归档而不是删除

1. 赛季材料在**评审/答辩/交接**场合可能仍被引用；
2. 部分推导过程（图表、创新点表述）在重写文档时可能有参考价值；
3. 删除会让 git 历史里的引用失效。

## 注意

- 第一类文档里的**数值、结论、模块划分**均按 2026 规则写成（英雄 42mm、
  大装甲 230 mm、17mm 弹 30 m/s 等），**2027 规则已变**（见
  `robot_types_and_aiming.md`）。
- 其中的代码路径 / 行号引用**早已失效**。
- 第二类文档引用 `../xxx.md` 时，若目标是活文档需回到 `docs/` 根目录。
