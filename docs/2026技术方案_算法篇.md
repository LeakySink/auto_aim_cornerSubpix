# 2026赛季技术方案 - 算法篇

## 1. 概述

### 1.1 背景&目标

在2026赛季，RoboMaster比赛规则和技术环境继续演进。基于2025赛季的技术积累和对同济大学2025赛季先进算法方案的研究，我校在本赛季的算法系统上进行了全面升级和创新。

**本赛季技术背景的主要变化：**

1. 算力硬件持续升级，NUC12等高性能计算平台的普及使得复杂算法实时化成为可能
2. 机器学习与传统视觉算法融合加深，YOLOv8/v11等模型在装甲板检测中表现优异
3. 模型预测控制(MPC)技术在机器人控制领域成熟应用，同济大学等强队已验证其优越性
4. 多传感器融合成为主流，IMU、激光测距、视觉等多源信息融合提升系统鲁棒性
5. 小陀螺等战术动作普及，对算法的动态跟踪性能提出更高要求

**基于对2025赛季同济大学算法方案的深入研究，我校在本赛季做出了以下战略决策：**

1. 全面引入MPC轨迹规划框架，替代传统决策树式控制逻辑
2. 采用EKF进行目标状态估计，提升对动态目标的预测精度
3. 构建模块化视觉框架，实现自瞄、能量机关、全向感知的资源共享
4. 优化系统延迟补偿机制，提升射击时机决策准确性

**本赛季我校机器人定位与目标：**

1. 实现基于MPC的高精度轨迹跟踪，稳态误差<0.5°，动态误差<2°
2. 支持小陀螺等复杂战术动作，装甲板切换响应时间<0.3s
3. 射击命中率显著提升，近距离>90%，中远距离>70%
4. 系统鲁棒性增强，多种环境光照条件下稳定运行
5. 为2026赛季后续开发预留扩展接口，支持快速迭代

### 1.2 其他学校算法方案分析综述

2025赛季，各强队在自瞄算法上呈现出明显的技术分化趋势：

#### 【第一梯队：MPC轨迹规划方案】

**同济大学**：率先将MPC引入RM自瞄系统，实现轨迹级别的优化控制。

**核心创新：**
- 使用TinyMPC求解器，实现<1ms的实时优化
- 提前减速策略处理装甲板切换，避免轨迹跳变
- 统一框架处理平移、低速旋转、高速小陀螺
- 实测效果：小陀螺跟踪稳定，命中率较传统方案提升30%以上

#### 【第二梯队：传统优化方案】

**华南理工大学、哈尔滨工业大学等**：采用传统PID+前馈控制，配合先进的预测算法。

- **优点**：成熟稳定，计算量小，易于调试
- **缺点**：对复杂运动状态适应性有限，小陀螺性能不如MPC方案

#### 【第三梯队：基础方案】

部分院校仍在使用简单的位置式控制，依赖视觉检测的精度。

**基于以上分析，我校选择以同济方案为基础进行深度开发：**

1. MPC方案在理论上有明显优势，是未来发展方向
2. TinyMPC等轻量级求解器使嵌入式实时应用成为可能
3. 轨迹优化框架可扩展性强，便于后续加入更多约束

### 1.3 机器人核心算法参数

基于MPC轨迹规划的视觉系统核心参数如下：

#### 【检测系统】
- 检测模型: YOLOv5/v8/v11可选，OpenVINO加速
- 置信度阈值: 0.8（可调）
- 检测帧率: 100-120fps（工业相机）
- 双重检测机制: 神经网络 + 传统灯条检测

#### 【跟踪系统】
- 状态估计: 11维EKF（位置、速度、角度、角速度、几何参数）
- 锁定速度: 连续5帧检测
- 丢失容忍: 15帧（标准）、75帧（前哨站）
- 收敛时间: 3帧（标准）、10帧（前哨站）

#### 【规划系统】
- MPC求解器: TinyMPC（ADMM算法）
- 预测时域: 100步 = 1秒
- 求解时间: <0.6ms（10次迭代）
- 加速度约束: Yaw 50rad/s², Pitch 100rad/s²
- 优化频率: 100Hz（与相机同步）

#### 【射击系统】
- 射击阈值: 0.0035rad（约0.2°）
- 延迟补偿: 40ms（可配置）
- 弹道补偿: 基于弹速的实时预测
- 自适应射频: 根据误差动态调整

## 2. 设计方案

### 2.4 算法设计

本赛季算法设计全面升级，采用模块化架构，核心模块包括：

#### 【系统架构】

与传统ROS系统不同，本系统采用单一可执行文件架构：

- **io层**: 硬件抽象（相机、云台、IMU）
- **tools层**: 工具库（EKF、弹道、YAML加载、线程安全队列）
- **tasks层**: 功能实现（自瞄、能量机关、全向感知）
- **src层**: 应用编排（主程序入口）

#### 【数据流】

```
相机线程 → 图像+时间戳 → 云台姿态（四元数）→ 检测器（装甲板四角）→ EKF估计器 → MPC规划器 → 控制器
```

#### 【核心创新：轨迹优化视角】

本系统采用轨迹优化而非传统决策树：

- **MPC求解器**: TinyMPC，专门为嵌入式系统设计
- **约束处理**: 硬约束（加速度限制）+ 软约束（跟踪精度）
- **提前减速**: 装甲板切换前主动减速，避免轨迹跳变
- **统一框架**: 平移、低速、高速旋转在同一优化框架下

### 2.4.1 视觉检测算法

#### 【神经网络检测】

采用YOLO系列模型进行装甲板检测：

1. **YOLOv5**: 兼容性好，推理速度快
2. **YOLOv8**: 精度提升，支持多尺度特征融合
3. **YOLOv11**: 最新版本，精度和速度最佳平衡

**模型优化：**
- 使用OpenVINO工具链转换为IR格式
- CPU/GPU自动选择，GPU模式推理速度提升3-5倍
- INT8量化，在精度损失<1%的情况下推理速度提升2倍

#### 【传统灯条检测】

作为神经网络的后备方案：

- 图像预处理: 二值化、形态学操作
- 灯条提取: 长宽比、角度、长度等几何特征过滤
- 装甲板匹配: 灯条对判定、平行度检查

### 2.4.2 目标状态估计算法

#### 【扩展卡尔曼滤波(EKF)】

**状态向量设计（11维）：**
```
x = [x, vx, y, vy, z, vz, angle, ω, r, l, h]ᵀ
```

- x, y, z: 旋转中心位置
- vx, vy, vz: 速度分量
- angle: 旋转角度
- ω: 角速度
- r: 旋转半径
- l: 长短轴差
- h: 高度差

**噪声模型：**
- 过程噪声Q: 分段白噪声模型，v1=0.9(线加速度), v2=100(角加速度)
- 测量噪声R: 自适应设计，根据装甲板朝向和距离动态调整
- 初始协方差P0: 根据机器人类型（2/3/4装甲板）差异化配置

**【装甲板匹配】**
- 预测所有装甲板位置，选择距离最近的3个作为候选
- 结合角度误差和距离误差进行最优匹配
- 检测装甲板切换，实现平滑过渡

### 2.4.3 MPC轨迹规划算法

#### 【问题建模】

**状态空间模型（2维）：**
```
x[k+1] = A*x[k] + B*u[k] + f
A = [1, DT; 0, 1], B = [0; DT]
DT = 0.01s, HORIZON = 100步
```

**优化问题：**
```
min Σ(x-x_ref)ᵀQ(x-x_ref) + (u-u_ref)ᵀR(u-u_ref)
s.t. x[k+1] = Ax[k] + Bu[k] + f
     |u[k]| ≤ max_acc
```

#### 【求解器】

**TinyMPC特点：**
- 算法: ADMM(交替方向乘子法)
- 求解时间: <0.6ms(10次迭代)
- 内存占用: <1MB
- 支持约束: 盒约束(加速度)、锥约束(未来扩展)

#### 【代价函数设计】

**状态权重Q: [9e6, 0]**
- Q[0] = 9e6: 位置跟踪权重（主导项）
- Q[1] = 0: 速度权重（设为0，仅约束位置）

**控制权重R: [1]**
- 惩罚控制量，产生平滑控制
- Q/R比例 = 9e6: 平衡跟踪精度与控制平滑

### 2.4.4 核心技术创新

#### 【创新1：轨迹统一优化框架】

传统方案使用决策树：不同运动状态使用不同控制器，切换逻辑复杂。

MPC方案：所有运动状态统一在单一优化框架下，自动平滑切换，理论保证最优性。

#### 【创新2：提前减速策略】

问题：4装甲板机器人旋转时，装甲板位置突变。

解决：检测到即将切换时，提前增大Q权重，优化器自动生成减速轨迹。

效果：切换后平滑加速，跟踪误差<2°。

#### 【创新3：自适应测量噪声】

根据装甲板朝向动态调整R矩阵，正面朝向高精度跟踪，侧面朝向降低测量权重。

#### 【创新4：NIS卡方检验】

实时监控滤波器性能，NIS>0.711(95%置信区间)时参数不匹配，需调整。

### 2.4.5 性能对比与优势

#### 【与传统方案对比】

主要指标对比：

| 指标 | 传统PID方案 | MPC轨迹优化方案 |
|------|-------------|-----------------|
| 稳态误差 | 1-2° | <0.5° |
| 动态误差 | 3-5° | <2° |
| 小陀螺跟踪 | 不稳定，易丢失 | 稳定，切换平滑 |
| 装甲板切换 | 有明显抖动 | 平滑过渡<0.3s |
| 响应时间 | 50-80ms | 40ms |
| 命中率(近距) | 70-80% | >90% |
| 命中率(远距) | 40-50% | 65-75% |

#### 【实测数据（2026年1月）】

- 处理帧率: 100fps（1280x720）
- MPC求解时间: 0.4-0.6ms
- 系统总延迟: 35-45ms
- CPU占用率: 30-40%（i7-1260P）

## 3. 创新发展方向

### 3.1 短期优化方向（2026春季赛）

#### 【方向1：参数自适应】

根据目标状态动态调整：距离自适应、速度自适应、环境自适应。

#### 【方向2：多目标优先级】

EKF同时跟踪多个装甲板，基于距离、威胁度、射击时机综合评分。

#### 【方向3：预测射击优化】

检查多个时刻进行射击决策，根据弹道散布模型动态调整阈值。

### 3.2 中期发展方向（2026夏季赛）

#### 【方向4：深度学习融合】

使用LSTM/Transformer预测目标运动轨迹，预测结果作为MPC参考轨迹。

#### 【方向5：强化学习优化】

使用RL优化MPC权重，离线训练+在线微调。

#### 【方向6：立体视觉】

双目/深度相机提升距离估计，与单目视觉融合。

### 3.3 长期研究方向（2027赛季）

#### 【方向7：端到端学习】

探索端到端深度强化学习：直接从图像到云台控制，省略中间模块。

- 优势: 可能突破传统算法上限
- 挑战: 需要大量数据，可解释性差
- 路线: 先仿真训练，再实车迁移

#### 【方向8：协同决策】

多机器人协同：英雄与无人机、哨兵的信息共享与协同决策。

- 共享目标状态估计
- 协同火力分配
- 战术配合（如无人机指示目标，英雄吊射）

#### 【方向9：自适应博弈】

考虑对手行为预测：

- 预测对手运动策略
- 博弈论优化射击时机
- 动态调整战术（预判对手走位）
