## 1. 关键判断：规范约束的是**下边缘**，不是板心

S124 原文：

> **S124** 地面机器人任意两块装甲模块**下边缘**高度差不得超过 100mm，
> 在机器人跨越地形时，允许其短暂不符合该条例。

S125：

> **S125** 对于地面机器人，变形前、中、后，装甲模块**下边缘**距离地面高度不得超过 400mm，
> 且装甲模块下边缘不得直接接触地面。

**规范全篇没有规定四块装甲模块的相对高度排布**，只规定：
1. 任意两块的**下边缘**高度差 ≤ 100mm
2. 下边缘离地 ≤ 400mm

所以"一低一高、两个中间高度"是**完全合规**的，而且你遇到的"最多差 10cm"正是
S124 允许的上限。我之前把它当成"异常工况"，是错的——**它是规范内的正常工况**。

## 2. 被规范直接推翻的假设

### ❌ A1-1 · 四块板分两组高度

规范：4 块板高度**互相独立**，只要任意两块下边缘差 ≤100mm。

我的模型（`h_armor_xyz`）：只有 `x[4]` 和 `x[4]+h` 两个高度，且强制
`z(0)=z(2)`、`z(1)=z(3)`。

| | 规范允许 | 我的模型 |
|---|---|---|
| 高度自由度 | 4 个独立（跨度 100mm） | **2 个** |
| 违反数 | — | 任意"一低一高两中"排布必然错 2 块 |

**必须改。**

---

### ❌ A1-2 · 竖直命中窗口 ±1.96cm 足够

规范：高度差上限 100mm（相对中心 ±50mm）。

我的竖直窗口（`eh = 板高 × 0.7 / 2 = 1.96cm`）：

```
50mm / 19.6mm = 2.55 倍  ← 超出窗口 2.5 倍
```

也就是说**规范允许的极限工况下，竖直偏差是命中窗口的 2.5 倍**，
那两块板物理上打不到（不是遮挡，是瞄不到高度）。

而且这不是"极限才出问题"：只要高度差超过 **39mm**（两倍窗口）就已经打不到了。
规范允许到 100mm，**中间 39~100mm 全是盲区**。

**必须改（要么 pitch 跟随，要么放宽竖直窗口 + 接受较低命中率）。**

---

### ❌ A1-3 · 四块板等角分布（严格 90°）

规范 S120 原文：

> **S120** …4 块装甲模块的方向向量需分别与机器人机体坐标系的正 X 轴、负 X 轴、
> 正 Y 轴、负 Y 轴一一对应，**方向向量和对应坐标轴之间的角度误差不能超过 5°**。

我的模型（`armor_xyza_list`）：

```cpp
angle = limit_rad(x[6] + id * 2π / armor_num_);   // 严格 90°
```

| | 规范允许 | 我的模型 |
|---|---|---|
| 板的**方向向量**与坐标轴 | 误差 ≤ 5°（即板朝向偏 ≤5°） | 严格按 `2π/4` 等角 |

**更正（2026-11-18）：这一条我之前算错了，实际不需要改。**

S120 约束的是板的**方向向量**（受击面法向在 XY 面的投影）偏 5°，
即**板绕自身竖轴的朝向**，不是"目标位置的方位角"。

板心位置的偏移只有 `r·Δθ = 0.20 × 0.0873 = 1.75 cm`，
在 4.5 m 处对应角度偏差 **0.222°**，占 yaw 窗口半宽（0.602°）的 **37%**。

我之前的错法是 `4.5 × tan(5°) = 39.4 cm` —— 把"板朝向偏"当成了
"整个目标在横向平移"，差了约 20 倍（r/d = 0.044）。

结论：**角距 ±5° 不影响命中判定，不需要建模。**

后果：关联代价系统性偏移，`w` 学歪；严重时关联错板。**这不是"精度问题"，
是模型不允许的几何自由度。**

**必须改（至少把角距做成可估或可配的）。**

---

### ❌ A1-4 · 板中心到旋转中心距离只有 2 个值（`r` 和 `r+l`）

规范 S121 原文：

> **S121** …安装于 Y 轴的单个装甲模块在发生偏移后，其几何中心相对于机器人的几何中心的
> **偏移量在 X 轴上的分量不得超过 50mm**，安装于 X 轴上的装甲模块同理。

即：**每块板的半径可以独立偏 ±50mm**（水平方向）。

我的模型：`r`（0/2 号）和 `r+l`（1/3 号），只有 2 个值。

| | 规范允许 | 我的模型 |
|---|---|---|
| 半径自由度 | 4 个独立（±50mm） | **2 个** |
| 50mm vs yaw 窗口 ±47mm | 1.06 倍 | 边缘可打，但不是 0 风险 |

**应该改**（优先度低于高度，但 50mm 确实略超窗口）。

**规范对底盘转速零约束。** 我假设的"绕竖直轴、匀速、单轴"三条全是我自己加的：

| 我的假设 | 规范依据 |
|---|---|
| 旋转轴竖直（不翻滚） | 无。只有 S123 限制"装甲模块相对底盘不得连续往复快速移动 >0.5m/s" |

| 单轴自转（无俯仰/横滚） | 无。只有 S125 允许"跨越地形"时短暂不合规 |
| 转速范围（我按 5 rad/s 设计） | **无依据**，需要实测或问对手 |

**这条最危险**：你提到的"部分战队小陀螺转速是 sin 函数"——规范完全不禁止。
如果对手确实这么干，我的 `w` 常数模型（`a += w·dt`，`w` 零阶保持）会持续滞后。

后果量化：`w` 从 0 变到 5 rad/s 时，我的模型只看 Q 的过程噪声（`q_yaw_acc_var`）
去追，`predict` 里 `w` 一阶保持，实际是"w 突变 → 预测错 → 靠观测拉回"，
每次估计滞后约 `q_yaw_acc_var` 决定的带宽（实测未标定）。

**必须做**：录一段对手真实小陀螺的 `.rlog`，看 `w` 的时序是否真的恒定；
如果是 sin/方波，需要把 `w` 的模型从"零阶保持"升级（比如加角加速度状态或
用正弦拟合）。

### ⚠️ A2-2 · 装甲模块的**下边缘**是水平线（板面俯仰固定 15°）

规范 S120：

> 装甲模块的装甲支撑架底部连接面需与 XY 平面平行，使得装甲模块受力面所在平面的法向量
> 所在直线与 Z 轴负方向所在直线的**锐角夹角为 75°**。装甲模块不含侧灯的两条边与 XY 平面
> 夹角小于 5°。

即：
- 板面法向与竖直方向夹角 **75°**（我代码里 `tilt_deg = 15.0`，等价，✅ 对上了）
- **"不含侧灯的两条边与 XY 平面夹角小于 5°"** ← 这条我完全没建模

后半句的意思是：板的**上/下边缘**允许相对水平面倾斜 5°。我的 `armor_geometry`
只有 `tilt_deg`（俯仰），没有"左右歪"的自由度。

后果：5° 的板面横滚 → PnP 的 yaw 估计偏。相对窗口（±4.7cm）影响约 5° 方位 → 39cm。
**需要建模或至少在 R 里体现。**

## 9. 2027 新增的重大变化：视觉特征从"灯条+贴纸"变成"点阵屏"

这是 2027 相比 2026 **对视觉影响最大**的一条，且目前**被官方"待公布"阻塞**。

规范 2.1.4 原文：

> 在 2027 赛季，裁判系统装甲模块**受击面为点阵屏幕**，受击面可以显示对应机器人编号或图案
> （**具体样式后续更新**）。
> 机器人视觉特征：**装甲模块显示的内容与其外观**。

对照 2026 的表述是"装甲模块两侧灯条、装甲贴纸、激光检测模块发光灯效与其外观"——那条已被替换。

### 对当前代码的影响

| 代码 | 现状 | 2027 要求 |
|---|---|---|
| `yolos/yolotup.cpp` / `detector.cpp` | 用**两侧灯条**的关键点做 PnP | 灯条模块仍在（表 3-3 重装 1 个），但**已不属于装甲视觉特征**；装甲板本身是否还有灯条未公布 |
| `classifier.cpp` + `assets/tiny_resnet.onnx` | 对装甲 ROI 做**贴纸数字**分类 | 目标变成**点阵屏显示内容**；样式未公布前无法训练 |
| `armor_properties` | 按贴纸数字/颜色枚举 38 类 | 类别定义需等官方样式 |

### 可以现在做的（不依赖样式公布）

1. **接口抽象**：把"ROI → 类别"做成可插拔（类别表与权重路径进 yaml），
   样式公布后只换模型不改代码。
2. **尺寸复核**：2027 已删装甲外形图，`small_width=0.135` / `lightbar_length=0.056`
   **失去规范依据**。必须用手上的裁判系统实物量一次，或等《裁判系统用户手册》更新。
3. **不假设灯条存在**：检测链路应对"装甲板没有两侧灯条"的情况留后路
   （比如纯贴纸/屏幕边缘检测、或用装甲支撑架的几何特征）。

### 明确被阻塞的事

- 点阵屏的图案样式：**官方明说"后续更新"** → 分类模型无法定型
- 装甲板物理外形（135/125/38 等）：2027 规范已删除，需等实物或新手册

**在样式公布前，任何"2027 装甲识别"的方案都是在猜。**

## 10. 附：2027 规则手册里与自瞄有关的数值

| 项 | 数值 | 出处 |
|---|---|---|
| 重装 42mm 射击初速上限 | **16.5 m/s** | 表 3-3、表 5-16 |
| 重装射击热量上限 / 冷却 | 300 / 100（每秒） | 表 5-16 |
| 步兵 17mm 初速 | 需 **>20 m/s**（S53 荧光充能自测要求，非上限） | 制作规范 S53 |
| 小能量机关转速 | 固定 **pi/3 rad/s** | 规则 5.6.3 |
| 大能量机关转速 | **spd = a·sin(wt) + b**，a∈[0.780,1.045]、w∈[1.884,2.000]、b=2.090-a，每次重置 | 规则 5.6.3 |
| 大能量机关转速实现误差 | 与目标函数时间误差 <=500ms | 规则 5.6.3 |
| 底盘小陀螺转速 | **无任何规定** | 两份手册均检索为 0 |

> **关于"sin 函数转速"**：sin 转速在规则里确实存在——但那是**大能量机关**的
> （`spd = a·sin(wt)+b`），不是底盘小陀螺。底盘转速规范里依然零约束，
> 所以"有战队做出 sin 转速底盘"是合规的，我仍需要真实数据才能确定模型。
