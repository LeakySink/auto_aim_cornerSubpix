# 重装自瞄系统基线（目标：命中率 ≥ 75%，高鲁棒性）

> 面向 2027 重装机器人（42mm / 16.5 m/s / 两阶段形态 / 大惯量云台）。
> 本文做两件事：**① 把"命中率 75%"翻译成可测量的工程指标，并拆成模块级误差预算；
> ② 给出每个模块的基线（必须达到什么）与检验方法（怎么证明达到了）。**
>
> 配套：`docs/heavy_robot_backend.md`（后端改造清单）、
> `docs/gimbal_mechanics_and_aiming.md`（机械→电控→自瞄）、
> `docs/robot_types_and_aiming.md`（2027 规则）、`docs/assumptions.md`（物理假设）。

## 0. 先把 75% 翻译成工程指标

命中判据：弹丸落在装甲板面内。2027 全兵种统一**小装甲 135×56 mm**
（大装甲已取消），故半宽 67.5 mm、半高 28 mm。

把瞄准误差建模为两轴独立同分布高斯（σ_aim），命中概率：

```
P = erf( (67.5/d) / (σ√2) ) · erf( (28/d) / (σ√2) )
```

数值解（本机计算）：

| 距离 d (m) | 板半宽角 (mrad) | 板半高角 (mrad) | **75% 所需 σ_aim** | 90% 所需 σ_aim | σ 折算到目标面 |
|---|---|---|---|---|---|
| 3  | 22.50 | 9.33 | 8.05 mrad | 5.67 mrad | 24 mm |
| 5  | 13.50 | 5.60 | 4.83 | 3.40 | 24 mm |
| 8  | 8.44  | 3.50 | **3.02** | 2.13 | 24 mm |
| 10 | 6.75  | 2.80 | 2.41 | 1.70 | 24 mm |
| 12 | 5.62  | 2.33 | 2.01 | 1.42 | 24 mm |
| 15 | 4.50  | 1.87 | 1.61 | 1.14 | 24 mm |

**顶层指标（全系统唯一）：**

> **σ_aim ≤ 24 mm（在目标所在平面）⟺ 命中率 ≈ 75%**
> **σ_aim ≤ 17 mm ⟺ 命中率 ≈ 90%**
>
> 换算成角误差：`σ_aim[mrad] = 24 / d[m]`。即 8 m 时 3.0 mrad、12 m 时 2.0 mrad。

注意这是**系统级 1σ**，不是"最好情况"。鲁棒性 = 在**所有分层**（距离/角度/光照/目标运动）
都保持 σ_aim ≤ 24 mm，而不是平均值达标。

## 1. 误差预算：24 mm 怎么拆

各模块贡献在"角度 mrad"域按平方和合成（同一 d 下等价于目标面 mm）：

```
σ_total² = σ_ckpt² + σ_pnpd² + σ_ekf² + σ_pred² + σ_ball² + σ_ctrl²
```

以 **8 m 为设计点**（σ_total 预算 3.02 mrad）：

| # | 模块 | 误差源 | 物理关系 | 基线要求 | 贡献 (mrad) |
|---|---|---|---|---|---|
| 1 | 检测关键点 → 姿态 | 角点像素噪声 | `σ_yaw ≈ σ_kp / f`（f=1818 → 1 px = 0.55 mrad，**与距离无关**）| σ_kp ≤ 0.8 px | **0.44** |
| 2 | 关键点 → 距离 → 抬枪 | 距离由板宽反解 | `σ_d ≈ σ_kp·d²/(f·W)`（d=8、1 px → **0.26 m**），再经 `∂pitch/∂d ≈ g·d/(2v²) ≈ 1.03°/m`（42mm/16.5）放大 | σ_kp ≤ 0.8 px **且** 多帧平滑 N≥8（σ_d 降 √N → 0.09 m）| **1.30** |
| 3 | 卡尔曼（含关联） | 状态估计残差 | 多帧融合等效降噪 | 位置 RMSE ≤ 0.1 m、关联不串号 | **1.00** |
| 4 | 预测 / 时间同步 | 延迟不确定度 | `σ ≈ v·σ_t/d`（v=2 m/s、σ_t=5 ms、d=8 → 1.25 mrad）| 时间戳 ≤5 ms、全链路延迟标定 ≤5 ms | **1.25** |
| 5 | 弹道模型 | 表拟合 + 弹速误差 | 表误差 0.05°=0.87 mrad；弹速 3% 偏差 → 0.26 m 等效 → 4.7 mrad | 表 vs RK4 ≤0.05°、**弹速闭环 ≤0.5%** | **1.50** |
| 6 | 云台控制（补偿后） | 相位滞后残差 + 齿隙/柔性 | 未补偿时 `e ≈ ω/(2π f_c)`：f_c=5 Hz、ω=1 rad/s → **32 mrad** | 必须辨识执行器模型并补偿；残差 ≤1.5 mrad | **1.50** |

合成：`√(0.44²+1.30²+1.00²+1.25²+1.50²+1.50²) = 2.73 mrad` ✓ 小于 3.02

**三条最重要推论**（决定了哪些模块是"必做"而非"优化"）：

1. **控制滞后是最大单项**：大惯量云台若不建模补偿，一个 1 rad/s 的目标就产生 32 mrad
   误差（超预算 10 倍）。→ MPC 必须含执行器模型（`docs/gimbal_mechanics_and_aiming.md` §2.3）。
2. **PnP 距离噪声经弹速放大后是第二大头**：单帧 1 px 角点噪声 → 0.26 m 距离误差 →
   4.7 mrad 抬枪误差。→ **多帧优化/BA 不是可选项**。
3. **弹速必须闭环**：3% 弹速误差 = 4.7 mrad。42mm 上限 16.5，超速红线 18（rmuc_C-013），
   所以要在 16.5 附近精确闭环。

**各距离的允收上限**（同样按 6 项分配，取 σ_total 为 75% 所需值）：

| d (m) | σ_total 上限 | 单模块允许上限 (÷√6) |
|---|---|---|
| 5  | 4.83 mrad | 1.97 mrad |
| 8  | 3.02 | 1.23 |
| 12 | 2.01 | 0.82 |
| 15 | 1.61 | 0.66 |

> 12 m 以上要求每个模块 ≤0.8 mrad，非常紧。**建议主战距离定位在 3–10 m**
> （12 m 以外靠"接近后再打"的战术，而不是硬扛精度）。

## 2. 模块基线（M0–M8）

每个模块给出：**目标 / 基线（必须做到） / 检验方法 / 验收阈值 / 典型失效**。
"检验"一列标注了四层体系中的层级（见 §3）：U=单元测试，O=离线回放，B=台架/静态靶，F=实车。

### M0 相机 · 时间同步 · 标定

| 项 | 内容 |
|---|---|
| 目标 | 提供"**曝光时刻**的图像 + **同一时刻**的云台姿态"，时间误差 ≤5 ms；内参/外参稳定 |
| 基线 | ① 固定曝光、关闭自动增益（过曝会导致检测静默，已实测）；② 曝光中点作为时间戳；③ 云台姿态按时间插值（现有 `Gimbal::q` 的 slerp）；④ 内外参用标定板复标，重投影 RMS ≤0.5 px；⑤ 明确卷帘/运动模糊上限 |
| 检验 | **U**：标定板全覆盖，重投影 RMS；**B**：LED 闪烁（已知周期）对拍测时间戳误差；**B**：让目标以不同角速度运动，测角点拖影像素；**F**：连续 30 min 看时间戳漂移 |
| 阈值 | 时间戳误差 ≤5 ms；重投影 RMS ≤0.5 px；目标最大角速度下运动模糊 ≤0.5 px |
| 失效 | 曝光过长 → 运动模糊（10 rad/s × 10 ms ≈ 0.1 rad）；时间戳取"读图时刻"而非曝光时刻 → 系统性超前/滞后一帧 |

### M1 YOLO 检测

| 项 | 内容 |
|---|---|
| 目标 | 3–15 m、±60° 偏航、场地光照下 **框检出率 P_n ≥0.98**（3–12 m）、≥0.95（12–15 m）；关键点 RMS ≤1 px；**零负样本**（空中机器人、场地灯、数字屏幕误识别） |
| 基线 | ① 输入分辨率：保证 12 m 处板 ≥10 px 等效；② 关键点回归带亚像素能力（σ_kp ≤0.8 px 是 §1 表第 2 行的前提）；③ 类别只保留机器人/前哨站/基地，**删除 `big` 类**（2027 无大装甲）；④ 输出必须带 score 与 4 个关键点，且顺序固定（TL,TR,BR,BL）；⑤ 遮挡鲁棒（重装允许 1 块板被遮挡） |
| 检验 | **O**：`eval_record` 采全分辨率数据 → `rlog_replay` 重跑，按**距离/偏航角/亮度**分桶统计检出率、关键点误差；**O**：负样本集（小飞机/场地灯）统计误检；**F**：实车先看 `raw`+发布图 |
| 阈值 | P_n ≥0.98（3–12 m）、≥0.95（12–15 m）；关键点 RMS ≤1 px；误检率 ≤0.1%/帧 |
| 失效 | 过曝/欠曝导致整帧静默；低分框（0.4–0.8）被阈值卡；大角度侧视时关键点崩；把空中机器人圆形灯组当装甲 |

### M2 关键点校验 · PnP · 轻量 BA（多帧位姿优化）

| 项 | 内容 |
|---|---|
| 目标 | 单帧姿态 σ_yaw ≤0.5 mrad；**距离 σ_d ≤0.09 m @8 m**（这是 §1 第 2 行的关键）；重投影 RMS ≤0.5 px |
| 基线 | ① PnP 用 IPPE + **几何消歧**（`n̂·p>0`，已实现）消掉 ±π 二义；② **关键点语义校验**（凸性/对边比/退化边，`keypoint_check.hpp` 已实现）作为前置门槛；③ **多帧重投影优化（轻量 BA）**：滑动窗口 N=5–10 帧，优化板在世界系的位姿（6 自由度）最小化重投影误差，初值取 EKF 先验；④ 物体点为 135×56 mm 矩形四角，顺序与检测器严格对应 |
| 检验 | **U**：合成位姿 → 反投影 → 加重噪声 → 检查估计误差与噪声的理论关系；**B**：静态靶已知卷尺距离，比较单帧 vs 多帧 σ_d；**O**：记录重投影残差序列 |
| 阈值 | 重投影 RMS ≤0.5 px；姿态误差 ≤0.3°；距离误差 ≤0.1 m @8 m（多帧后） |
| 失效 | ±π 未消歧 → 关联锁死 0 号板（已修但需复验）；侧视时距离病态（`σ_d ∝ 1/cos yaw`）；只做单帧 → 距离噪声直接放大成抬枪误差 |

> **为什么必须有 BA**：§1 表显示，单帧角点噪声经"距离→抬枪"放大后贡献 4.7 mrad，
> 是唯一超预算的单项。多帧优化把 σ_d 降 √N，是**唯一**能把它压回 1.3 mrad 的手段。

### M3 卡尔曼滤波 · 数据关联

| 项 | 内容 |
|---|---|
| 目标 | 状态估计残差 ≤1 mrad；**NIS 越限率 3–10%**（名义 5%，证明模型与噪声自洽）；不串目标；丢目标后重捕 ≤200 ms |
| 基线 | ① 11 维 EKF（现有）；② **关联空间门控**（现有，容差 `1.0+0.2·dist`）+ **旋转方向门控**（只允许按 `sign(w)` 推进）；③ **NIS 比例看门狗**（已修：比例 ≥40%、样本 ≥30）；④ 观测噪声 R 自适应（**侧向板距离观测按 `|cos armor_yaw|` 放大 R**，尚未做）；⑤ 多目标航迹管理（现有单 `target_`，需补匈牙利/航迹 ID）；⑥ 快速旋转下用**相位差分**给 `w` 弱观测 |
| 检验 | **U**：蒙特卡洛验证 NIS 服从 χ²(4)、NEES 一致性（`tests/algo/ekf_update_check.cpp` 已有先例）；**O**：`python -m rdbg metrics <rlog>` 看 NIS 越限率、`w` 过零次数、`a` 斜率与残差；**F**：多目标场景看是否串号 |
| 阈值 | NIS 越限率 3–10%；位置 RMSE ≤0.1 m；`armor_id` 随旋转正常推进（无 A↔B 来回跳）；重捕 ≤200 ms |
| 失效 | 关联退化（恒 0 号板）；R 用后验量导致 NIS 失真；`w` 学不出来 → 预测滞后；单航迹被第二个同类目标污染 |

### M4 弹道解算

| 项 | 内容 |
|---|---|
| 目标 | 弹道 pitch 误差 ≤0.05°（0.87 mrad）；**弹速闭环 ≤0.5%**；覆盖 3–15 m、h∈[−2,2] m 全域 |
| 基线 | ① `ballistic-main` 多项式表（已接，含**补角语义** `pitch+atan2(h,d)`，已修）；② 重装用 `big.csv`（42mm）并**补 V=16.5 档**；③ 回退 RK4 的 `k` 按弹种（42mm ≈0.00513）；④ **弹速实时闭环**（CAN 测速模块）+ 超速保护（16.5 上限、18 硬红线；⑤ 表外自动回退并记录 |
| 检验 | **U**：`tests/algo/ballistics_poly_check.cpp` 与物理 RK4 对拍（**必须覆盖 h≠0**，v0∈{16,16.5,17}）；**B**：静态靶打靶纸，测弹着高 vs 解算 pitch；**O**：记录 `used_poly`/回退原因 |
| 阈值 | 表 vs RK4 ≤0.05°；实测弹着高误差 ≤24 mm @8 m；弹速闭环 ≤0.5% |
| 失效 | 用 17mm 表解 42mm 弹道；漏加视线仰角（已修，近处高目标完全打不到）；回退 k 用 17mm 值；弹速未闭环导致远距离系统性偏低 |

### M5 提前量 · 预测 · 延迟补偿

| 项 | 内容 |
|---|---|
| 目标 | 预测误差 ≤1.25 mrad；全链路延迟标定误差 ≤5 ms |
| 基线 | ① `fly_time` 定点迭代（现有）；② **全链路延迟分段标定**：曝光→检测→解算→CAN 下发→云台到位→出膛；③ 时间戳统一到"曝光中点"；④ 云台相位滞后纳入 MPC 时域（见 M6）；⑤ 分形态延迟（重装装 42mm 后云台到位时间显著变长） |
| 检验 | **U**：合成匀速/正弦目标轨迹，检查预测角误差；**B**：阶跃测各段延迟（相机触发→图像时间戳、下发→编码器到位）；**F**：移动靶（匀速 2 m/s、正弦 1 Hz）命中率 |
| 阈值 | 各段延迟标定误差 ≤5 ms；移动靶命中率 ≥60% |
| 失效 | 用单一常数延迟（步兵 0.055 s）套重装；时间戳取错；`fly_time` 迭代不收敛 |

### M6 云台控制 · MPC

| 项 | 内容 |
|---|---|
| 目标 | **跟随误差（补偿后残差）≤1.5 mrad**；无振荡/无振铃；阶跃超调 ≤10% |
| 基线 | ① **执行器辨识**：每轴每形态拟合 `G(s)=K·e^{−Ls}/(Ts+1)`，得 `(K,T,L,α_max)`——重装 4 组形态；② MPC 状态扩充（角/角速度/角加速度）或显式加一阶滞后；③ `max_*_acc` 按形态设置（重装装 42mm 后 ~5/10 rad/s²，而非 50/100）；④ 打通前馈（当前 `Gimbal::send` 丢弃 `*_acc`、`distance` 硬编码 3 m）；⑤ 齿隙/回差补偿 |
| 检验 | **B**：阶跃响应 → 拟合 `(K,T,L)`、测 `α_max`、测超调与到位时间；**B**：正弦跟踪扫频（0.2–5 Hz）测幅频/相频，得 −3 dB 带宽与相位曲线；**F**：实车打移动靶看残差 |
| 阈值 | 阶跃超调 ≤10%、到位时间符合模型预测 ±10%；跟踪残差 ≤1.5 mrad @目标角速度；无自激振荡 |
| 失效 | MPC 纯双积分器模型 + 大惯量 → 规划不可实现轨迹；未补偿滞后（1 rad/s 目标 32 mrad）；齿隙导致换向偏一发；轴系柔性振铃被 EKF 当成目标运动 |

### M7 开火判定 · 时序

| 项 | 内容 |
|---|---|
| 目标 | 开火时刻的预测命中概率 ≥0.8；空放率 ≤10%；42mm 每轮 3 发都用在有效窗口 |
| 基线 | ① 判据改为"**实测云台角 vs 理想瞄点**"，而非当前比较 MPC 内部 `traj` 与 `x`；② 阈值动态化（按距离/板面尺寸/预测不确定度）；③ 把弹道误差**投影到板面坐标系**再比板尺寸；④ 形态相关延迟与判决点偏移；⑤ 自适应装甲下优先选未加固区（×1.5） |
| 检验 | **O**：离线回放，用真值计算"若此刻开火是否命中"的比例，扫阈值得 ROC；**F**：实车按裁判判定统计每发命中 |
| 阈值 | 开火时刻预测命中概率 ≥0.8；空放率 ≤10% |
| 失效 | 未到位就开火（判据看内部量）；过热/锁枪未处理；一轮 3 发全浪费 |

## 3. 四层检验体系：每层能证明什么

| 层 | 手段 | 能证明 | **不能**证明 | 现有工具 | 需补 |
|---|---|---|---|---|---|
| **U 单元** | 合成数据 + 数值断言 | 数学正确性（PnP/滤波/弹道公式） | 真实噪声特性、时序 | `tests/algo/`（ekf_update_check、ballistics_poly_check、limit_rad_check 等）| BA/多帧优化、开火 ROC |
| **O 离线回放** | 录制的全分辨率帧 + 真值 | 检测/估计/预测在**真实数据**上的表现；可复现、可回归 | 云台真实响应、弹着点 | `eval_record`、`rlog_replay`、`rdbg metrics` | 逐发"若开火是否命中"评估 |
| **B 台架/静态靶** | 卷尺 + 靶纸 + 阶跃/扫频 | 弹着点、标定、云台动力学 `(K,T,L,α_max)`、延迟 | 对抗中的目标机动 | **需新建**：阶跃标定程序、靶纸测量流程 | 阶跃/扫频脚本、靶纸统计模板 |
| **F 实车对抗** | 真实对抗 + 裁判判定 | **最终命中率**（唯一权威） | 单模块归因（除非配合 O/B） | — | 分距离/角度的记录表 |

**归因原则**：实车命中率不达标时，**先用 O 排除感知/估计，再用 B 排除弹道/云台**，
剩下才是战术/操作问题。跳过 O 和 B 直接调 F 是浪费时间的主要来源。

## 4. 统计口径（否则 75% 会自欺欺人）

1. **样本量**：要在 95% 置信、±5% 误差下确认 p≈0.75，需
   `n ≥ 1.96²·0.75·0.25/0.05² ≈ 288 发`。**每个距离桶 ≥300 发**。
2. **分层下界**：不能只看总体。要求
   `总体 ≥75%`、`3–5 m / 5–8 m / 8–12 m 每桶 ≥65%`、`±45° 偏航每侧 ≥65%`。
3. **命中定义**：以**裁判系统判定**为准（法向速度门槛：17mm >12 m/s、42mm >8 m/s，
   见 `robot_types_and_aiming.md` §2）。板面命中但速度不足不算命中。
4. **散布 σ 的测量**：按规则定义——所有命中点在**装甲模块坐标系**（左下角原点）里，
   取横纵中位数 (x0,y0)，σ = 各点到该点距离的**中位数**（rmuc_C-026）。
   这个 σ 同时是自适应装甲里 ρ 的输入，**必须能测**。
5. **置信区间**：`p ± 1.96·√(p(1−p)/n)`。报告必须带 n 与区间，不能只写"命中率 75%"。
6. **单轮口径**：42mm 一轮约 3 发（热量 +100/上限 300），需分别报告
   "**单发命中率**"与"**一轮内至少 1 发命中率**"——后者才是战斗效能。


```
│   ├─ 弹着系统性偏高/偏低 → M4（弹道表/弹速闭环）+ M0（标定/外参）
│   ├─ 弹着随机散布大     → M6（齿隙/柔性）+ M2（距离噪声）
│   ├─ 阶跃超调大/振荡    → M6（MPC 参数、执行器模型）

    ├─ 打静止靶准、打移动靶不准 → M5（延迟/提前量）
    ├─ 移动靶在换向时偏       → M6（齿隙）+ M3（关联）
    └─ 都准但命中率仍低       → M7（开火时机）+ 战术（选择交战距离）
```

## 附：本文数值的计算脚本

`σ_aim` 由下式数值解出（两轴独立高斯 × 矩形板面）：

```python
from math import erf, sqrt, atan
W2, H2 = 0.0675, 0.028           # 小装甲半宽 / 半高（m）
def P_hit(d, sig_mrad):
    a, b = atan(W2/d)*1000, atan(H2/d)*1000
    return erf(a/(sig_mrad*sqrt(2))) * erf(b/(sig_mrad*sqrt(2)))
# 二分求 P_hit = 0.75 / 0.90 对应的 sig_mrad
```

结论：**75% ⟺ σ_aim ≈ 24 mm**（3–15 m 全程几乎恒定，因为它按角度缩放）。
